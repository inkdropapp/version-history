## Preferences UI for Local HTTP Server & Security improvement

As the local HTTP server feature has been used for [the Inkdrop MCP server](https://github.com/inkdropapp/mcp-server), I thought it'd be necessary to provide the UI for configuring it.

![New Preferences UI for Local HTTP Server](https://uploads.inkdrop.app/attachments/user-d975606d93c067c5ef8d6adfb5db83b5/file:yQvV6osC/index-public)

By pressing the **View Server Logs** button, you can view the server logs.
It allows you to easily track the server access and errors.

![View server logs](https://uploads.inkdrop.app/attachments/user-d975606d93c067c5ef8d6adfb5db83b5/file:y4GewxZK/index-public)

On top of that, if you configured it via the UI, your username and password are encrypted in the config file, as the following:

```js
"server": {
  "auth": "djEwYnxxxxxxhCfUf+znfNMySOxxxxxxxxxxxTlL5hxzFdaNM/tZoXY3IjkE5CHI95RDPJEMeKSIxxxxxxxxxxxxxg==",
  "bindAddress": "127.0.0.2",
  "enabled": true,
  "port": 19841
},
```
